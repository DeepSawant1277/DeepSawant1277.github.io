# Deep Sawant — Personal Portfolio V2

## Included
- Premium dark AI/developer design
- Animated typing headline
- Interactive particle background
- Mouse-following glow
- Smooth scrolling + reveal animations
- Active navigation on scroll
- Animated skill bars
- Project category filters
- Clickable project detail modals
- Live GitHub profile/repository section for DeepSawant1277
- Certifications, journey and hobbies
- Contact form using the default email client
- Resume button placeholder (`resume.html`)
- Responsive mobile navigation
- Back-to-top button

## Run
Open `index.html` in VS Code and use Live Server, or open it directly in a browser.

## Resume
Add your resume as `resume.html` or change the Resume button in `index.html` to your actual PDF, e.g. `href="Deep_Sawant_Resume.pdf"`.

## Profile photo
The current hero uses a stylized DS avatar. Replace the `.avatar` element with an `<img>` if you want to use a real photo.
